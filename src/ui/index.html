    What this is
    
        
    Reads playerSaveData.txt from your Clicker Heroes install and turns it into a plan. It never writes to the save, never touches the running game, and never needs the internet.
    

        
    The tabs
    
        
    Plan — ordered steps: push/ascend, transcend, ancients, hero, gilds, rubies, progress, mercs. Each step says when, what, and why.
    
        
    Ancients — # buy order, Cur current level, Sug suggested level, Diff how many to buy. Greyed rows with skip are useless for your build.
    
        
    Heroes — game order by default, sortable by DPS, cost, level or gilds. +N after a name is the gild count; the Gild column is the damage bonus.
    
        
    Mercs — quest countdown, rarity, level, and the save's death timer. Dead mercs show failed / dead (detected from questResult).
    
        
    Outsiders — same columns as ancients; bought with Ancient Souls after a transcendence.
    
        
    Gilds — which hero holds them, the bonus they give (50% + 2% per Argaiv level), and DPS share.
    
        
    Relics — only the bonuses your ancients actually use, with the computed amount.
    
        
    ? — this page. ⚙ — build, theme, font size/family/density, save source, save conversion, weights, updates.
    

        
    Keys
    
        
    Ctrl+Shift+M minimise · Ctrl+Shift+H hide/show · Ctrl+Shift+R reload · Ctrl+Shift+Q quit. Drag the title bar to move it.
    

        
    Where the numbers come from
    
        
    Game formulas ported from dfederm/ClickerHeroesTracker. Progression rules from McNiibot (the official Discord bot). Gilding chart from clickerheroes.dev. Merc quest order re-derived from qubit64's optimisation; revive windows from qubit64 and dukC2.
    

        
    Glossary
    
        
    e-notation (logHS / logGold) — in 2.94e39 the number after the e is the order of magnitude (39). Always read the exponent first: e39 vs e46 is seven orders, not "a bit more".
    
        
    OOM — order of magnitude: one e step.
    
        
    MPZ — monsters per zone (10). Fewer monsters per zone means faster zones; speed comes from zone count per hour, not from bigger hits.
    
        
    Kappa — rare centurion (boss zone ending in 0), 0.5% on PC, 0.4% mobile, halved during events, only above zone 1000.
    
        
    FANT — First Ascension New Transcendence: the run right after a transcendence. 2x damage does nothing here.
    
        
    TP / AS / HS / BP — Transcendent Power / Ancient Souls / Hero Souls / breakpoint (see /bp tiers in the Plan).
    
        
    AC / QA / TL — Auto Clicker / Quick Ascension / Timelapse.
    

        
    External tools
    
        
    The community treats macros and external auto-clickers as cheating-adjacent, but nothing enforces it. This app reads your save file only — it never writes to it, never reads game memory, and never injects input. That keeps it a companion, not a cheat.
